## 函数

### 剩余参数

```typescript
function sum(...numbers:number[]) { 
  return numbers.reduce((result, item) => result + item, 0);
}
sum(1, 2, 3, 4, 5);
```



### this 类型注解

`this` 不是参数，是保留字，是函数签名的一部分

```typescript
function showDate(this: Date) { 
  return `${this.getFullYear()}-${this.getMonth() + 1}-${this.getDate()}`
}
// showDate(); //error
showDate.call(new Date()); 
// showDate.call(null); // 如果"strictBindCallApply":false不会报错
```

### 重载

拥有多个重载声明的函数调用，是按重载声明的顺序**从上往下**查找的，因此，**兜底的重载声明**应该放在最后

Typescript 的重载是**伪重载**，它的重载体现在**方法调用的签名上**，而不是具体函数实现上



## 泛型

### 类型别名与泛型

```typescript
type Nullable<T> = T | null | undefined
```



### 泛型的默认类型 "="

```typescript
type MyEvent<T = HTMLElement | null> = {
  target: T
  type: string
}
const myEvent: MyEvent = {
  target: document.querySelector("#myButton"),
  type: "click"
}
```
