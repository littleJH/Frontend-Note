## keyof

`keyof` 操作符能将对象类型**所有属性的键的类型转为字面量类型**，然后组成联合类型

```typescript
type User = {
  id: number
  name: string
  age: number
}

type UserKeys = keyof User // keyof User = 'id' | 'name' | 'age'
```

结合 `typeof` 操作符，获取对象上所有键的类型

```typescript
const user = {
  id: 1,
  name: 'hayes',
  age: 19
}

type UserKeys = keyof typeof user  // "id" | "name" | "age"
```

也可以和 “方括号运算符” 结合

```typescript
type Person = {
  age: number;
  name: string;
  sex: boolean;
};

type A = Person[keyof Person] // number|string|boolean
```



## in 运算符遍历

`in` 运算符除了在**控制流分析**中类型守卫的作用外，在**索引签名类型/映射类型**中，`in`还能遍历**联合类型**中的每一个类型

```typescript
type U = 'a'|'b'|'c';

type A = {
    [P in U]: string
}

// 等同于
// type Foo = {
//   a: string,
//   b: string,
//   c: string
// };
```

与 `keyof` 结合泛型使用，增加通用性

```typescript
type User = {
  id: number
  name: string
  age: number
}

type Copy<T> = {
    readonly [P in keyof T]+?: T[P]
}

type CopyUser = Copy<User>
/*
type CopyUser = {
    readonly id?: number | undefined;
    readonly name?: string | undefined;
    readonly age?: number | undefined;
}
*/
```

## 条件类型与类型兼容性 extends

1. 原始类型 < 原始类型对应的装箱类型 < Object
2. any/unknown 是所有类型的顶层类型（父类型）
3. never 是所有类型的子类型

```typescript
type T = 1 extends number ? true : false;  // true

type T1 = 1 extends number ? true : false;  // true
type T2 = "1" extends number ? true : false;  // false
type T3 = string extends object ? true : false;  // false
type T4 = { a: 1 } extends object ? true : false;  // true
type T5 = { a: 1, b: 2 } extends { a: 1 } ? true : false;  // true
type T6 = { a: 1 } extends { a: 1, b: 2  } ? true : false;  // false
type T8 = string extends {} ? true : false; // true

type T9 = {} extends object ? true : false; // true
type T10 = object extends {} ? true : false; // true
type T11 = {} extends Object ? true : false; // true
type T12 = Object extends {} ? true : false; // true
type T13 = Object extends object ? true : false; // true
type T14 = object extends Object ? true : false; // true

type T15 = string extends any ? true : false; // true
type T16 = Object extends any ? true : false; // true
type T17 = Object extends unknown ? true : false; // true

type T18 = any extends Object ? 1 : 2; // 1 | 2
type T19 = any extends "Hello" ? 1 : 2; // 1 | 2

type T20 = unknown extends any ? 1 : 2; // 1
type T21 = any extends unknown ? 1 : 2; // 1
```

## 分布式条件特性

**条件类型+联合类型+泛型**时，会触发分布式条件特性

| 分布式条件类型                                  | 等价于                                                       |
| ----------------------------------------------- | ------------------------------------------------------------ |
| `string extends T ? A : B`                      | `string extends T ? A : B`                                   |
| `(string | number) extends T ? A : B`           | `(string extends T ? A : B) | (number extends T ? A : B)`    |
| `(string | number | boolean) extends T ? A : B` | `(string extends T ? A : B) | (number extends T ? A : B) | (boolean extends T ? A : B)` |

实现 `MyInclude、MyExclude`工具类型

```typescript
type User = {
  id: number
  name: string
  age: number
}

type MyPick<T, K extends keyof T> = {
    [P in K]: T[P]
}

type MyInclude<T, U> = T extends U ? T : never
type MyExclude<T, U> = T extends U ? never : T

type MyOmit<T, U extends keyof T> = MyPick<T, MyExclude<keyof T, U>>;

type OmitResult = MyOmit<User, 'id' | 'name'>;
/*
type OmitResult = {
    age: number;
}
/*
```



## 映射类型的属性过滤

实现上面的 `MyOmit` 类型工具，除了 `MyPick + MyExclude` 方法外，还可以使用 `as + never` 进行 **映射类型的属性过滤**

```typescript
type MyOmit1<T, U extends keyof T> = {
    [P in keyof T as P extends U ? never : P]: T[P]
}

type OmitResult1 = MyOmit1<User, 'id' | 'name'>;
```



## infer 推断

```typescript
type Flatten<T> = T extends (infer U)[] ? U : T

const arr = [
  { id: 1, name: "aaa" },
  { id: 2, name: "bbb" },
  { id: 3, name: "ccc" }
];

type A = Flatten<typeof arr>	// {id: number, name: string}
```

`infer` 意为推断，在**条件类型**中声明**泛型 `U`**，表示待推断的泛型，当执行时，TypeScript 会**自动将 U 进行类型推断**，上面的例子中，U 会被推断为 `{id: number, name: string}`



实现`Frist`类型工具，获取数组类型的第一个元素的类型

```typescript
type Frist<T extends any[]> = T extends [infer F, ...infer R] ? F : never;
type FirstResult = Frist<[1, 2, 3]>	// 1

// 使用方括号运算符
type First1<T extends any[]> = T extends [] ? never : T[0]
// 另一种写法
type First2<T extends any[]> = T["length"] extends 0 ? never : T[0]
```



实现 `Swap` 类型工具，交换元组两个位置上的类型

```typescript
type Swap<T extends any[]> = T extends [infer F, ...infer R, infer L] ? [L, ...R, F] : T
type SwapResult = Swap<[1, 2, 3, 4]>    // type SwapResult = [4, 2, 3, 1]
```
